Paste the code an agency or platform gave you, or start from a template. Pixel Lab fills the IDs into labelled fields, runs the code on the real page and reads back exactly what it sent. In Safe mode the data is caught at the browser's edge and never reaches the platform.

How it stays safe

  • Safe mode blocks outbound tracking for the tab at the browser level. The code runs, the data is recorded, and nothing is delivered.
  • Everything is stored locally in the browser. No server, no account, no telemetry.
  • Imported pixels must be reviewed before they can run.

What it isn't

Pixel Lab shows what a page did in one browser, with one consent choice, at one moment. That's evidence for a review, not a legal opinion or a certification that a site is compliant. Confirm Live results in each platform's own tools, such as Meta Test Events or GA4 DebugView.
