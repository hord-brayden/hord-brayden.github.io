link: STANDBY — press CONNECT
TASK UPLINK provisions a WiFi network over Bluetooth — the unit joins it and reports its LAN address on the OLED, for the full console. STATUS/THREATS/etc. stream over BLE with no association.
Your phone becomes the unit's uplink. The set talks to this page over Bluetooth; this page forwards to the internet over your phone's connection. The unit never needs WiFi — same shape as how smart glasses reach the cloud through a paired phone.

These settings are stored only in this browser (localStorage), never in the page and never uploaded. This is a public site — nothing you type here is committed anywhere.
Sync sends only new events since the last successful upload, tracked per unit, so nothing is duplicated.
